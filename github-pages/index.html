Sleep, Workout, Diet in One Flow

개인 맞춤형 웰니스 코치 웹 앱

수면, 운동, 식단을 하나의 흐름으로 연결해 관리하는 웰니스 코치 웹 앱입니다.
이 페이지는 GitHub Pages용 정적 소개 버전이며,
인증과 AI Chat이 포함된 전체 앱은 Vercel 배포 버전에서 이어집니다.

Authentication Credentials + 3 Social Providers
Plan Focus Sleep, Workout, Diet
AI Chat 서버 기반 Q&A 응답

Project Flow

현재 구현된 핵심 사용자 흐름

로그인 이후 온보딩, 플랜 워크스페이스, 코치 대시보드, AI Chat으로 이어지는 구조를 중심으로 기능을 설계했습니다.

Step 1

Onboarding

목표 체중, 수면 패턴, 운동 경험, 식단 스타일을 입력받아 이후 개인화 기준으로 저장합니다.

Step 2

Plan Workspace

수면, 운동, 식단 우선순위를 전환하고 브리핑 입력과 함께 현재 플랜 방향을 확인합니다.

Step 3

Coach Dashboard

가입 시 입력한 프로필, 플랜 요약, 주간 리포트를 묶어 개인 대시보드 형태로 보여줍니다.

Step 4

AI Chat

추천 질문과 요약 카드, 최근 질문 흐름과 함께 일반 웰니스 정보형 AI 답변을 제공합니다.

Tech Stack

현재 프로젝트 구현 기준 기술 스택

프론트엔드 UI부터 인증, 상태 관리, AI 연동, 정적 소개 페이지 운영까지 현재 코드 기준으로 정리했습니다.

Framework

Next.js 16.2.3

App Router, 서버 컴포넌트, Route Handler, Server Action 활용

UI

React 19.2.4

인터랙티브 코칭 UI와 클라이언트 컴포넌트 구현

Language

TypeScript 5

프론트엔드와 서버 로직 전반의 타입 안정성 확보

Styling

Tailwind CSS 4

반응형 레이아웃과 커스텀 UI 스타일링 구성

Authentication

NextAuth v5 beta

Google, Kakao, Naver 로그인과 보호 라우트 구성

Security

Node.js crypto

scrypt 기반 비밀번호 해시 및 인증 정보 보호 처리

State

Zustand

웰니스 플랜과 브리핑 입력 상태를 브라우저 저장소와 동기화

AI Integration

Gemini REST API

서버 Route Handler를 통한 웰니스 Q&A 응답 생성

Data Storage

JSON + Cookie

fs/promises 기반 로컬 사용자 데이터와 httpOnly 쿠키 기반 온보딩 보정값 저장

Static Preview

GitHub Pages

프로젝트 소개용 정적 랜딩 페이지를 별도로 운영

Deployment

Vercel

로그인과 AI Chat이 포함된 메인 Next.js 앱 배포
